# 恢复切换下蹲与姿态过渡

地图分支从GitHub master `28f6a89` 建立时，独立分支上的 `4f0df37`（toggle crouch with synchronized posture transitions）尚未包含在该基线中。因此地图分支一直保留按住C下蹲、松开站起、姿态瞬间切换的旧实现；最近的地图改动没有删除动画资源，但实际使用体验确实丢失了此前的切换与过渡。

本次只应用该提交中 `PlayerController.ts`、`CharacterAnimation.ts` 的下蹲差异，不合并整条分支，不覆盖当前地图、8名敌人、人物模型或其他动画修复。

- 按C切换目标姿态，按键重复事件不连续切换，松开保持。
- 视角和身体骨骼共用0.25秒过渡；动作中途反向或切换到开火、移动、装填等状态时从当前姿态继续。
- 胶囊在落地时一次切换；头顶受阻时保持蹲姿；失焦保留已经生效的姿态；重生恢复站立。

验证：`tsc --noEmit`通过；`tools/check-crouch-runtime.js` 在LayaAir 3.4.1实际预览中通过。覆盖C按下/长按/释放、第二次C、快速反转、头顶遮挡及解除、暂停恢复、空中请求落地后生效、下蹲开火/持刀/开镜、装填期间站起、重生复位。控制台无错误或警告。

逐帧采样显示眼高从1.61逐步过渡到0.96米，同时髋部世界高度从约0.874过渡到0.224米，并出现Animator交叉淡化状态；不是仅移动相机。原始数据见 `crouch-restoration-checks.json`。
