## 几何决策

**史料支持**：地点身份、起义背景、现存文保对象。史料不足以支持本轮任何精确尺寸或逐户地块边界。

**现存建筑参考**：以正面共同轮廓为主要约束，建立中部升高的对称山墙、斜肩、顶层成对圆拱窗、中央圆窗及两侧小圆窗、下部圆拱门。不建通用欧洲双塔或尖顶。坐东朝西取自二手资料，作为暂定朝向，后续取得测绘应复核。

**保守估算**：教堂主体宽26米、纵深48米，约1248平方米矩形占地，最高含十字架约22.65米，仅与约1300平方米量级做合理性对照，不声称二者为同一面积口径。屋顶中高侧低、侧窗与壁柱节奏、青灰瓦和低饱和砖石色均为未有充分历史细部证据的补全。立面圆窗分格简化；壁龛留空，不杜撰圣像、文字和徽记。教堂外观封闭，不提供教堂内部游戏区域。

**游戏设计补全**：总平面外包范围约99×74米（含边界），实际铺地采用L形，只是一段街区。入口巷、交火街口、折转通道、教堂前院、普通民居、北侧任务建筑与撤离巷全是可调整布局，并非现实街道走向的断言。入口约6米宽；局部门廊净宽约4.35米；任务建筑门洞净宽2.4米、高2.8米。砖砌矮掩体、木箱、手推车、排水沟、家具和空白纸张均为原创游戏道具。没有虚构历史招牌、公文内容、弹痕或战损。

四名敌人、两处清敌、取文件、撤离属于现有虚构玩法，本轮不生成敌人、不更动任务脚本。取件位置在 `04_MissionBuilding_Fictional` 的普通虚构建筑内，绝不标为真实档案室、司令部或指挥所。参考路点仅帮助后续接入；没有宣称与1927年真实部队行军路线相同。

后续最有价值的补证为：文保测绘立面/剖面、修缮前后分期对照、带摄影日期的早期照片及有比例尺的旧城地籍图。取得前，优先修订对应模块，不随意拉伸地标迁就旧灰盒。
