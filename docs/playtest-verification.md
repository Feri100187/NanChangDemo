## 发布方式

- 安装的 LayaAir IDE 3.4.1，项目版本仍为 3.4.1；使用 IDE 的 Web build，不复制源码工程充当运行包。
- 停止预览、关闭并重开 Demo01，再构建。启动场景为 Demo01；导出场景的四名敌人、2+2 分组、文件节点、距离及瞄准容差与源场景一致。
- 分发器沿导出场景／预制体／材质／动画依赖收集资源，并处理 Laya 的 `.glb` → `@0.lh` 运行时映射。保留引擎及默认 UI 支持文件，排除未引用的旧模型与贴图。fileconfig.json 保留 IDE 原索引，其中部分旧素材条目不对应分发文件，运行期间没有请求这些未使用条目。
- 构建文件、独立试玩目录、截图和压缩包均不提交源码。仓库只添加配置、分发器、启动器、署名、说明和必要修复。

## 实际修复

独立包出现步枪横向压成细条。检查发现 PlayerProvidedRifle.localScale 为 `(6.25, 5.555555..., 0.952380...)`，但 localMatrix 仍为单位矩阵，导致灰盒父节点缩放未被抵消；敌人武器也存在同类问题。
在浏览器将同一 localScale 重新赋给公开 setter 后，矩阵与步枪外观立即恢复。CharacterAnimation.onAwake 现在只在现有武器子树重新应用原位置、旋转、缩放一次，使矩阵失效并正确重算。没有遍历修改骨骼，没有改模型、动画、碰撞、AI、伤害、射速或任务条件。
修复后发布包中检查玩家与四名敌人的五个武器实例，矩阵均与原属性值相符，截图确认玩家枪械恢复。另修复了分发器最初未识别模型导出映射导致的 404；没有修改引擎安装。
