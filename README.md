# NanChangDemo

LayaAir 3.4.1 基础第一人称移动场景。打开 `assets/Scene.ls` 并运行即可试玩。点击游戏画面锁定鼠标后开始操作；按 Esc 释放鼠标，再次点击可继续。

| 操作 | 按键 |
| --- | --- |
| 前后左右移动 | W / S / A / D |
| 旋转视角 | 移动鼠标 |
| 跳跃 | Space，落地后才能再次起跳 |
| 疾跑 | 按住 Shift |
| 下蹲 | 按住 C，松开站起 |
| 连续射击 | 按住鼠标左键 |
| 开镜 | 按住鼠标右键 |
| 主动换弹 | R，弹匣未满且有备弹时 |

场景包含 100×100 米平地、网格参照、胶囊体玩家、第一人称相机和操作提示。胶囊网格在运行时隐藏，物理碰撞保留。
两侧有盒体拼接的简易房屋，中央通道旁有两段错开的掩体墙。门洞可以进入，实体墙与屋顶带静态碰撞，会挡住玩家、敌军视线和双方的射线射击；窗板是封闭墙面上的外观装饰。
普通移动 / 疾跑 / 蹲行速度为 5 / 9 / 2 米每秒；玩家站立高 2 米，下蹲高 1.2 米。
开镜移动速度为 1.5 米每秒，按住右键时 Shift 不会触发疾跑；松开右键后恢复原有移动速度。
在 Player 节点的 PlayerController 组件中可以调节速度、起跳速度和鼠标灵敏度。WASD 按视角水平朝向移动，仰视或俯视不会让角色飞起或钻地。
如果 IDE 内嵌预览阻止鼠标锁定，点击画面后仍可在画面范围内移动鼠标转向；按 Esc 退出该模式。

当前步枪以长方体代替，使用射线命中检测，没有实体子弹。初始弹匣 40 发、备弹 99999 发，射速 700 发/分钟，换弹耗时 2.2 秒。弹匣打空会自动换弹；按住左键穿过换弹过程时，完成后会继续射击。

枪上有橙色机械瞄具边框和中心红点。按住右键时，相机会移到与红点共线的视点，完全对齐后屏幕十字准星会隐藏；松开后返回普通视点，视野角始终是 60°。腰射连射时镜头逐发上抬、屏幕准星同步上移，射线始终沿准星方向发射；开镜时红点保持在画面中心，镜头带着红点视线和射线上抬。松开左键后后坐角度逐渐恢复。

平地上现在是简易敌军，初始 100 HP。其状态为 Idle、Patrol、Alert、Combat、Dead：短暂站岗后在几个固定点间巡逻，看到玩家会逐渐警戒，进入战斗后转向并用射线开枪；玩家跑出视距或被物体挡住时，警戒下降并能重新巡逻。敌军射击每次造成 8 点伤害。玩家初始 100 HP，归零后不能移动或射击，重新运行场景可重试。

玩家步枪仍按部位结算伤害：头部 70、躯干和手臂 28、腿部 18.2。敌军血量归零后进入永久 Dead，外观和碰撞一起关闭。

移动和碰撞使用 Bullet CharacterController。姿态切换在落地时生效，空中保持起跳时的姿态；头顶有遮挡时保持下蹲。
斜向移动会归一化，按住空格不会自动连跳，失焦会清除输入，跌落场地下方后会返回起点。

逻辑位于 `src/PlayerController.ts`，节点和物理组件保存在场景中。
针对 IDE 3.4.1 的旧组件热重载报错，项目内的 `src/EditorHotReloadGuard.ts` 仅在场景编辑器中生效。
